# MA 터치 스캐너

S&P 500, Russell 2000, 내 관심종목 가운데 당일 가격이 **50일 SMA / 200일 SMA / 100일 VWMA**에 닿은 종목을 미국 장중 1시간마다 찾아 디스코드로 보냅니다.

## 설치 (약 10분, 코딩 불필요)

### 1. 디스코드 웹훅 만들기
1. 알림 받을 디스코드 서버에서 채널 하나 생성 (예: `#ma-터치`)
2. 채널 톱니바퀴 → **연동** → **웹후크** → **새 웹후크**
3. **웹후크 URL 복사** (이 주소는 비밀번호와 같으니 공개하지 마세요)

### 2. GitHub에 올리기
1. github.com 가입 후 **New repository** → 이름 입력 → **Public** 선택 → 생성
   - Public이면 실행 시간이 무료·무제한입니다. Private은 월 2,000분 한도입니다.
2. **uploading an existing file** 클릭 → 이 폴더의 파일을 모두 끌어다 놓기 → Commit
   - `.github` 폴더는 숨김 폴더라 안 보일 수 있습니다. 안 올라갔으면 **Add file → Create new file**에서 이름을 `.github/workflows/scan.yml`로 적고 내용을 붙여넣으세요.

### 3. 웹훅 주소 등록
저장소 **Settings → Secrets and variables → Actions → New repository secret**
- Name: `DISCORD_WEBHOOK_URL`
- Secret: 1번에서 복사한 주소

### 4. 테스트
**Actions** 탭 → **MA Touch Scanner** → **Run workflow** → 실행
몇 분 뒤 디스코드에 표가 오면 끝입니다. 이후에는 자동으로 돕니다.

## 설정 바꾸기

`scanner.py` 맨 위 설정 부분의 기본값을 고치면 됩니다.

| 항목 | 기본값 | 의미 |
|---|---|---|
| `SCAN_GROUPS` | sp500,russell2000,watchlist | 감시할 그룹 |
| `TOL_PCT` | 1.0 | 터치 허용 오차(%). 선의 ±1% 안에 들어오면 터치로 봄. 0이면 선을 실제로 지나야 함 |
| `ONLY_FROM_ABOVE` | 0 | 위·아래 양방향 터치 모두 포함. 1이면 전일 종가가 선 위였던 종목만 (눌림목) |
| `MIN_PRICE` | 5 | 이 가격 미만 제외 |
| `MIN_DOLLAR_VOL` | 5000000 | 50일 평균 거래대금($) 하한 |

관심종목은 `watchlist.txt`에 한 줄에 하나씩 적습니다.

## 알아둘 점

- **시세는 야후 파이낸스 무료 데이터**라 약 15분 지연되고, 가끔 일부 종목이 빠질 수 있습니다.
- **GitHub 예약 실행은 정시보다 5~30분 늦을 수 있습니다.** 분 단위 정확도가 필요한 용도는 아닙니다.
- 같은 종목·같은 선은 **하루 1회만** 알립니다.
- 이동평균은 **당일 진행 중인 봉을 포함**해 계산하므로 장중에 값이 조금씩 움직입니다.
- 미국 공휴일에는 데이터가 없어 아무것도 보내지 않습니다.
- 저장소에 60일간 변경이 없으면 GitHub이 예약 실행을 멈춥니다. 메일이 오면 Actions 탭에서 다시 켜면 됩니다.
