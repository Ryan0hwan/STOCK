# MA 터치 스캐너

S&P 500과 내 관심종목(약 680종목) 가운데, 상승 추세 종목이 **50일 SMA / 100일 VWMA / 200일 SMA**에 닿으면 디스코드로 알려줍니다. 별도로, **많이 하락한 종목**이 **일봉 SMA325 / 주봉 VWMA100 / 월봉 VWMA100** 장기 지지선에 닿으면 📉 섹션으로 알려줍니다. 미국 장중 하루 4회 자동 실행됩니다.

## 알림 조건 (모두 충족해야 알림)

| 구분 | 조건 |
|---|---|
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 $500만 이상 |
| 정배열 | 50일 SMA > 200일 SMA |
| 기울기 | 50일선이 20거래일 전보다 높고, 200일선이 약 1개월 전보다 높음 |
| 상대강도 | 최근 3개월·6개월 수익률이 모두 SPY보다 높음 |
| 터치 | 당일 저가~고가가 선의 ±0.8% 안에 걸침 |
| 방향 | 위에서 내려온 눌림목 + 아래에서 올라온 회복 모두 |
| 선 위 마감 | 현재가(마감 후엔 종가)가 그 선 위 |
| 첫 터치 | 위에서 내려온 경우만: 이전 20거래일 동안 종가가 그 선 아래로 간 적 없음 |

- 최근 상장주는 200일선(정배열)과 기울기 계산에 약 222거래일이 필요해 그 전까지는 알림이 오지 않습니다.

## ⭐ [확률높은종목] (추가 알림)

기존 알림은 그대로 오고, 그중에서 아래 3개 조건을 **모두** 통과한 종목은 마지막에 **⭐ [확률높은종목]** 표로 한 번 더 모아서 보냅니다.

| # | 조건 | 기준 |
|---|---|---|
| ① | **거래량 감소 눌림** | 오늘 거래량 < 50일 평균의 80% (장중에는 경과 시간으로 하루치 환산) **그리고** 눌림 구간 평균 거래량 < 직전 상승 구간(고점 전 20일) 평균 |
| ② | **주도주** | 52주 고점 대비 −25% 이내 **그리고** 최근 3개월 안에 저점→고점 +20% 이상 상승한 이력 |
| ③ | **강화된 정배열** | 50일선 > 150일선 > 200일선 |
| + | 눌림만 | 전일 종가가 선 위에 있다가 내려온 터치만 (아래에서 올라온 회복 터치는 제외) |

```
⭐ [확률높은종목] Oct 16 | 거래량 감소 눌림 · 주도주 · 50>150>200 정배열 (1)
TICKER  MA              LAST   HIGH%  RUNUP%   VOL%  PULL%  DESCRIPTION
TEST    50D SMA        93.00    -7.5    27.9     40     30  Test Corp
```

| 열 | 의미 |
|---|---|
| HIGH% | 52주 고점 대비 현재가 |
| RUNUP% | 최근 3개월 안의 최대 상승폭 (저점→고점) |
| VOL% | 오늘 거래량 ÷ 50일 평균. **낮을수록 조용한 눌림** |
| PULL% | 눌림 구간 평균 거래량 ÷ 직전 상승 구간 평균. **낮을수록 좋음** |

표는 선(50D → 100D VWMA → 200D) 순, 같은 선 안에서는 VOL%가 낮은 순입니다.

## 📉 장기 지지선 터치 (많이 하락한 종목 전용)

위의 상승 추세 조건(정배열·기울기·상대강도)과 **별개로**, 크게 빠진 종목이 장기 지지선에 닿는 경우를 따로 잡습니다.

| 조건 | 기준 |
|---|---|
| 많이 하락 | 52주 고점 대비 **−25% 이상** 하락 |
| 터치 | 오늘 가격 범위가 선의 ±1%(일봉 SMA325) / ±2%(주봉 VWMA100) / ±3%(월봉 VWMA100) 안 |
| 선 위 마감 | 종가가 선 위 |
| 선이 상승 중 | 일봉: 1개월 전보다 / 주봉: 13주 전보다 / 월봉: 6개월 전보다 높음 (**하락하는 장기선은 지지가 아니라 저항**이라 제외) |
| 오랜만의 첫 터치 | 최근 6개월(월봉은 12개월) 동안 종가가 그 선 아래로 간 적 없음 |
| 반등 캔들 | 걸러 내지 않고 표시만: 종가가 당일 범위 상위 50%면 REV `OK` |

```
📉 장기 지지선 터치 Oct 27 | 고점 대비 -25% 이상 하락 종목 (1)
TICKER  LINE              MA      LOW     LAST   HIGH%  SLOPE%  REV  NAME
TEST    D-SMA325      112.43   112.09   113.55   -29.7    +3.9   OK  Test Corp
```

| 열 | 의미 |
|---|---|
| LINE | D-SMA325 = 일봉 325일 SMA · W-VWMA100 = 주봉 100주 VWMA · M-VWMA100 = 월봉 100개월 VWMA |
| HIGH% | 52주 고점 대비 |
| SLOPE% | 선의 상승률 (일봉 1개월 · 주봉 13주 · 월봉 6개월 전 대비) |
| REV | OK = 반등 캔들 |

- 주봉·월봉 선은 하루에 거의 움직이지 않아서, **장 마감 무렵 회차(뉴욕 15:30 이후)에만** 판정합니다. 수동 실행(Run workflow)에서는 항상 판정합니다.
- 월봉 VWMA100은 약 8년치(100개월), 주봉 VWMA100은 약 2년치가 필요합니다. 상장 기간이 짧으면 그 선만 건너뜁니다.
- ⚠️ 하락 종목의 바닥 잡기(역추세) 매매입니다. 반등 캔들이나 다음 날 확인 후 진입하는 것이 안전합니다.

## 실행 시각 (한국 기준)

**23:35 / 01:35 / 03:35 / 05:35**, 평일 4회. GitHub 특성상 5~30분 늦을 수 있습니다.

- 서머타임 기간(3~11월): 마지막 회차가 장 마감 직후라 하루 확정 결과
- 서머타임 해제 기간(11~3월): 마지막 회차가 마감 25분 전

## 파일 구성

| 파일 | 역할 |
|---|---|
| `scanner.py` | 스캐너 본체. 맨 위 설정 부분에서 조건 변경 |
| `watchlist.txt` | 관심종목. `티커, 회사명` 형식으로 한 줄에 하나 (회사명 생략 가능) |
| `.github/workflows/main.yml` | 자동 실행 일정 |
| `requirements.txt` | 필요한 파이썬 패키지 |

## 적용 방법 (기존 저장소에 덮어쓰기)

1. 저장소에서 **Add file → Upload files**
2. `scanner.py`, `README.md`를 끌어다 놓고 커밋 (`watchlist.txt`는 직접 수정한 게 있으면 올리지 마세요)
3. `.github/workflows/main.yml`은 숨김 폴더라 업로드가 안 될 수 있습니다. 저장소에서 그 파일을 열어 연필 아이콘으로 편집하고, 이 zip 안의 `main.yml` 내용으로 통째로 바꿔 커밋하세요.

디스코드 웹훅(`DISCORD_WEBHOOK_URL`)은 이미 등록돼 있으므로 다시 할 필요 없습니다.

## 수동 실행

**Actions → MA Touch Scanner → Run workflow**. 언제든 가능하며 가장 최근 거래일 기준으로 판정하고, 중복 방지가 꺼져 있어 조건에 맞는 종목이 모두 옵니다. 끝나면 `✅ 테스트 완료: N종목 확인, 터치 N건 · 확률높은종목 N건 · 장기 지지선 N건` 메시지가 옵니다.

## 설정 바꾸기 (`scanner.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `SCAN_GROUPS` | sp500,watchlist | 감시 그룹. 겹치는 종목은 앞 그룹(S&P 500)에만 표시 |
| `TOL_PCT` | 0.8 | 터치 허용 오차(%) |
| `ONLY_FROM_ABOVE` | 0 | 1이면 위에서 내려온 눌림목만 |
| `REQUIRE_GOLDEN` | 1 | 정배열 조건 (0이면 해제) |
| `REQUIRE_SLOPE` | 1 | 기울기 조건 |
| `REQUIRE_RS` | 1 | 상대강도 조건 |
| `REQUIRE_CLOSE_ABOVE` | 1 | 선 위 마감 조건 |
| `FIRST_TOUCH_DAYS` | 20 | 첫 터치 판정 기간 (0이면 해제) |
| `MIN_PRICE` | 5 | 최소 주가($) |
| `MIN_DOLLAR_VOL` | 5000000 | 50일 평균 거래대금 하한($) |
| `HP_ENABLE` | 1 | [확률높은종목] 표시 (0이면 끔) |
| `HP_VOL_MAX` | 0.8 | ① 오늘 거래량 상한 (50일 평균 대비 배수) |
| `HP_PIVOT_LOOKBACK` | 40 | ① 눌림 시작점(최근 고점)을 찾는 기간 |
| `HP_RALLY_DAYS` | 20 | ① 직전 상승 구간 길이 |
| `HP_NEAR_HIGH` | 25 | ② 52주 고점 대비 허용 하락폭(%) |
| `HP_RUNUP` / `HP_RUNUP_DAYS` | 20 / 63 | ② 최근 63거래일 안의 최소 상승폭(%) |
| `LT_ENABLE` | 1 | 📉 장기 지지선 섹션 (0이면 끔) |
| `LT_DRAWDOWN` | 25 | 52주 고점 대비 최소 하락률(%) |
| `LT_TOL_D` / `LT_TOL_W` / `LT_TOL_M` | 1 / 2 / 3 | 일봉·주봉·월봉 선 터치 허용 오차(%) |
| `LT_ONLY_LAST_RUN` | 1 | 1이면 장 마감 무렵 회차에서만 판정 |

## 알아둘 점

- 시세는 야후 파이낸스 무료 데이터라 약 15분 지연되고, 야후에 없는 티커는 조용히 빠집니다.
- 이동평균은 당일 진행 중인 봉을 포함해 계산하므로 장중 회차마다 값이 조금씩 다릅니다.
- 같은 종목·같은 선은 하루 1회만 알립니다 (자동 실행 기준).
- 저장소에 60일간 변경이 없으면 GitHub이 예약 실행을 멈춥니다. 안내 메일이 오면 Actions 탭에서 다시 켜면 됩니다.
